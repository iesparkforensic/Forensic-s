# Site Opener (Windows)

Opens a list of websites in your default browser, one every 10 seconds. Nothing to install.

## How to use

1. Open `sites.txt` in Notepad and put one site per line (`https://` is optional, lines starting with `#` are ignored).
2. Keep `sites.txt` in the same folder as `open_sites.bat`.
3. Double-click `open_sites.bat`. Close the black window to stop early.

For a different interval, open Command Prompt in the folder and run `open_sites.bat 5` (5 seconds).
